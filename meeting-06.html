Build and test a mission attachment

Week 6 defines the next model action, attachment change, measurements, and evidence. Today turns that plan into a controlled build and a five-run comparison.

Agenda

  1. 10 min Review the Week 6 mission-action plan and agree on the one result the robot must produce.
  2. 25 min Build the planned attachment change or code adjustment. Verify the attachment can return to its starting position.
  3. 15 min Check the two planned measurements, alignments, or sensor readings on the field.
  4. 20 min Run five controlled trials and record success, time, contact point, and failure mode.
  5. 10 min Compare this result to the previous version using the same start and model reset.
  6. 10 min Capture the next question for Week 7: what must change, and what should remain fixed?

Goals

  • The attachment or code change is built from the Week 6 plan
  • Two planned measurements are checked before the full test
  • Five trials create a usable comparison with the previous version
  • The team records a specific revision target for the next homework
