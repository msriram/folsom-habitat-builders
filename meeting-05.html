Build and test attachment version 2

Week 5 supplied the model target, sketch, route, and five-run test plan. Today the team builds that version, tests it fairly, and records the evidence for the next design choice.

Agenda

  1. 10 min Read the Week 5 design brief. Agree on the model, home base, attachment action, and success rule before touching the build.
  2. 25 min Build attachment version 2 and fit it to the base robot. Check clearances for wheels, sensors, hub, and cable routing.
  3. 15 min Set the route and starting position from the marked wireframe. Take any missing field measurements before testing.
  4. 20 min Run the planned five trials. Record success, failure mode, time, and the one observation that explains each result.
  5. 10 min Make one controlled adjustment only, then run two confirmation tries.
  6. 10 min Keep, revise, or defer the attachment. Record the next design question for Week 6.

Goals

  • One attachment version is physically built and safely fitted to the base robot
  • Five comparable trials are recorded from the same home base and reset
  • The test record names a failure mode, not just a score
  • The team decides one next attachment change using the recorded evidence

Bring

Test rule

Do not change the robot start, model reset, and program at the same time. One controlled change gives the record a useful answer.
