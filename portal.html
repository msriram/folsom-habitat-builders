Week 1 · Builds the field and baseline

Set up the mat, test the base robot, and choose a first run

Due Friday, August 14Click to expand
Task 1

Check the field setup

Confirm the table is flat, the mat is centered against the wall, Dual Lock is clicked, and every model start is photographed.

Robot mission planField setup, screenshots, scoring, and route groupsTable instructionsOfficial dimensions and border guidance
Task 2

Measure the base robot

Record whether the robot and planned equipment fit the inspection limits. Note anything missing—especially the mat or mission models.

Task 3

Run three baselines

Test a straight drive, a turn, and a wall-square. Record what happened and one change that could make the next run more repeatable.

Task 4

Choose one first mission family

Pick a small, compatible run such as M08/M11 or a left-field seed experiment. Explain why the team should learn from it first.

Choose a team name and a cause anchor

Task 1

Read the parent opening-day deck

Use the deck for the season rhythm, field/table plan, and starting name ideas. It is context for the team—not a set of adult decisions.

Parent opening-day deckDownload the presentation shared by the coach
Task 2

Connect our Week 0 interests

Start with the three interests we have heard: biodiversity across climatic zones; Burmese python and invasive species; and adaptations in plants and animals. What question could connect two or more of them?

Task 3

Propose a name

Choose a name that is easy to say, fits BIOGLOW, and can grow with our project. Possible directions include BioBeacons, Habitat Heroes, Eco Explorers, Nature Ninjas, or your own idea.

Task 4

Attach a real cause

Pair the name with a social or environmental cause: local biodiversity observation, invasive-species awareness, habitat connectivity, climate adaptation, or another problem people can investigate and improve.
