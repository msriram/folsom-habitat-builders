Build and compare an attachment revision

Week 7 identifies a real failure, proposes one revision, and defines a fair comparison. Today the team builds only that revision and lets the test record decide what happens next.

Agenda

  1. 10 min Read the revision target and decision rule from Week 7. Confirm what stays fixed for a fair test.
  2. 25 min Build the revised attachment. Label the changed piece, contact point, and travel direction before it is mounted.
  3. 15 min Run the original version twice as a baseline with the same home base, model reset, and program.
  4. 20 min Run the revised version five times under those same conditions and record the complete result.
  5. 10 min Compare the two versions: success rate, time, model contact, and failure pattern.
  6. 10 min Decide to keep, revise, or defer using the Week 7 decision rule.

Goals

  • Only the planned attachment revision changes between comparison runs
  • Original and revised versions use the same reset and program
  • The group records enough evidence to make a keep, revise, or defer decision
  • The next homework begins with a real test question, not a guess
