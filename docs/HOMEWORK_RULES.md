# Homework timing and content rules

These rules govern every team homework assignment:

1. Homework Week X is due two days before Session X.
2. Homework Week X questions must refer to work completed in Session X-1, so students can reflect on and prepare from real team work.
3. Do not change an already-published homework assignment.
4. Coach, student, and parent views use the same homework plan and questions. Only visibility differs: coaches can see every planned week; students and parents can see only homework that has been made available to them.
5. A published homework assignment is immutable. Never overwrite its title, due date, questions, or resources. If a correction is required, preserve the original and create a separate coach-approved follow-up instead.
